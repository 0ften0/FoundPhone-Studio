# 当前进度

AI 脚本玩家入口、可选 App 安装、桌面编辑、小组件、聊天、社交内容、通知、模拟电话、密码、分支、结局、存档和静态构建已接入。

正式模板使用少量中性演示数据。默认演示展示聊天阅读、模拟来电和 Instagram 动态解锁；纯空白作品单独保留。用户自己的作品主要修改 stories/，无需修改手机 UI。

发布准备仍需验证构建、剧情和浏览器回归；GitHub 仓库与在线演示在用户确认目标账号和公开范围后创建。不能把尚未部署的地址当成可访问演示。

已知边界：49 个 App 注册入口的页面覆盖程度不同；未承诺所有 App 的所有页面达到真机 1:1。真机 Safari、长按与手势仍需要设备测试。运行时不连接真实社交服务，不进行真实通话或支付，不依赖在线 AI。
